# 小红书笔记格式 Skill

适用来源：实时新闻、个人素材、微信文字/语音、网页录音和成片文案。

输出目标：一篇可以快速审核的小红书知识型或经历型笔记。

结构：

1. 标题不超过 20 个汉字，直接表达痛点、变化或结果。
2. 第一段用两三句话给出钩子，不复制公众号导语。
3. 正文拆成 3 至 5 个短要点，每个要点只讲一件事。
4. 个人素材优先写真实经历；实时新闻优先写“对普通人有什么影响”。
5. 结尾保留一个问题，邀请读者分享经历。
6. 最后附 3 至 6 个相关话题，避免无关热词。

禁止：

- 不把公众号长文直接截短。
- 不使用绝对化承诺、收益保证或制造焦虑。
- 不编造亲身经历和未核验的数据。
