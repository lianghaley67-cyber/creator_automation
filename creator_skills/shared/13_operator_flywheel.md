# 运营增长飞轮 Skill（普通人视角·实用价值版）

**定位**：以普通职场人、自媒体人的真实使用视角，挖掘一个工具/资讯对普通人的深层实用价值。
不是工具发布通报，不是功能清单，而是：这个工具能帮你在哪几件具体的事上省力、省时、做得更好。

---

## 核心写作视角（每篇必须选一个主轴）

**主轴 A：自媒体效率**
这个工具怎么具体改变"选题→写作→发布→复盘"流程？能省掉哪一步的重复劳动？
适合人群：正在做公众号/小红书/短视频的普通创作者。

**主轴 B：职场提效**
这个工具怎么帮普通职场人处理日常工作？比如写报告、整理会议记录、理解复杂文档、排查问题。
适合人群：不写代码、不是极客、只是想少加班的普通上班族。

**主轴 C：学习效率**
这个工具怎么帮你更快看懂一个新领域、一份长文件、一套复杂系统？
适合人群：想学AI但时间碎片化、没有系统学习路径的人。

> 注意：一篇文章只选一个主轴写深，不要三个都蜻蜓点水。选哪个取决于原始资讯最适合被翻译成哪个场景。

---

## 公众号输出结构（严格按此顺序）

**① 标题**
不要写工具名 + 功能介绍，要写"普通人用这个工具之后，什么变了"。
示例格式：
- 「我用 Claude Code 做自媒体选题，发现它真的能省掉最烦的那一步」
- 「不会写代码的职场人，用 Claude Code 能干什么？」
- 「Claude Code 帮我看懂项目文档，这是我用过最省脑子的一种方法」

**② 开头（1-2句，直接点题）**
不介绍工具背景，直接说"我碰到了什么麻烦，然后我试了这个"。
格式：[我遇到的一个具体场景] + [今天我想分享的一个发现]
禁止：不要从"XX工具发布了""XX功能上线了"开始，不要从官方介绍开始。

**③ ## 它到底能帮普通人做什么**
从所选主轴出发，给3-5个具体维度，每个维度必须是：
- 场景：[什么情况下]
- 动作：[你怎么用它]
- 结果：[你能省掉什么、得到什么]

不写功能名称堆砌，每个维度落到"你今天能做的一件事"。

**④ ## 我是怎么开始用的（真实入口）**
给一个最小启动路径，3步以内：
1. 第一步去哪里找到它（官方入口，不猜测）
2. 第一次打开后先做什么
3. 用什么内容/素材测试效果

如果没有官方链接证据，写"建议直接搜索官网，不要从第三方下载"，不编造链接。

**⑤ ## 我踩过的坑 / 它的边界在哪**
诚实说明：
- 它能做什么，它不能替你做什么
- 什么情况下它会让你失望
- 什么情况下它会帮你节省大量时间

这一段让读者觉得"这个人是真的用过的，不是帮工具打广告"。

**⑥ ## 今天就能做的一个动作**
一个10-15分钟内完成的最小任务，具体到：
- 用什么素材（一篇文章 / 一份会议记录 / 一个项目目录）
- 输入什么提示词（给一个可直接复制的版本）
- 期待看到什么结果

**⑦ ## 写在最后**
一句话回到长期视角：这类工具的价值不在于你知道它，而在于你形成了一个可以重复的使用习惯。
结尾给一个选项式互动问题，例如：
「你现在最想用AI帮你省哪一步？A 写公众号开头，B 整理会议记录，C 看懂复杂文档，D 做选题」

---

## 小红书输出结构

**第一行**：反常识钩子 + 普通人视角
示例：「会用Claude Code的自媒体人，正在把别人要2小时的活压到20分钟」

**正文节奏**：
1. 我的判断：一句话说它对普通人的价值
2. 适合谁：用具体场景描述（不是"适合所有人"）
3. 我怎么用它（3步，具体到点哪里、输入什么）
4. 避坑：1条真实限制
5. 可复制提示词（一个可直接用的）
6. 互动问题（选项式）

---

## 必须包含

- 一个具体的使用场景（不是泛泛而谈的"提效"）
- 一个可直接复制的提示词或操作步骤
- 一处真实的限制或边界说明（让内容有可信度）
- 一个结尾的选项式互动问题

---

## 禁止

- 不从官方功能列表开始写
- 不写"赋能""范式""颠覆""革命性"等词
- 不编造链接、价格、收益数字
- 不写"值得关注""建议了解""可能改变"这类没有实际内容的话
- 不写"### 第一步：" 格式（只用 1. 2. 3. 或自然叙述）
- 不堆砌工具功能名称
- 不把文章写成工具安装教程（安装步骤最多3行，不展开）

---

## 示例标题

- 「我用Claude Code写了半年公众号，它真的帮我省掉了这几件事」
- 「职场人用Claude Code不需要会写代码，但这几个用法要知道」
- 「Claude Code帮我看懂了一个陌生项目，用了不到10分钟」
- 「这个工具能帮自媒体人做什么？我用了两周，总结了3个真实场景」

---

## 示例可复制提示词

**自媒体选题场景**：
「我是做AI科普内容的自媒体人，这是今天的一条AI新闻：[粘贴内容]。请帮我从普通职场人的角度分析：1）这件事对不懂技术的人意味着什么；2）它能帮普通人省掉哪个具体动作；3）给我3个适合公众号/小红书的标题方向，每个标题直接说读者能得到什么。」

**职场效率场景**：
「帮我整理这份会议记录：[粘贴内容]。输出格式：决定事项3条，待办事项（含负责人和时间），下次会议需要确认的问题。不要添加原文没有的内容。」

**学习效率场景**：
「这是一份我不太懂的技术文档：[粘贴内容]。请用普通职场人能看懂的语言，解释它在解决什么问题、我今天能用它做的一件事、有哪些地方需要我自己核验而不是完全相信它。」
